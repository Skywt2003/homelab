证书安装指南

安装并信任 HomeLab Caddy Internal CA 根证书后，设备就可以正常访问 *.lab.skywt 的 HTTPS 服务。

下载 root.crt

只在你自己控制的设备上安装这张根证书。这里提供的是公开根证书，不是私钥； 不要分发 Caddy 数据目录里的 *.key 文件。

iOS / iPadOS

  1. 用 Safari 打开本页，下载 root.crt，按提示安装描述文件。
  2. 打开“设置”，在顶部的“已下载描述文件”中完成安装。
  3. 进入“设置 -> 通用 -> 关于本机 -> 证书信任设置”。
  4. 打开对 HomeLab Caddy 根证书的完全信任。

macOS

  1. 下载 root.crt，双击导入“钥匙串访问”。
  2. 把证书放到“系统”钥匙串，或按你的使用范围放到“登录”钥匙串。
  3. 打开证书详情，在“信任”里将 SSL 设置为“始终信任”。
  4. 重新打开浏览器，再访问 https://index.lab.skywt 验证。

Linux

  1. 下载 root.crt 到本机。
  2. Debian / Ubuntu：复制到 /usr/local/share/ca-certificates/lab-skywt.crt。
  3. 运行 sudo update-ca-certificates。
  4. Fedora / RHEL：复制到 /etc/pki/ca-trust/source/anchors/，然后运行 sudo update-ca-trust。

Windows

  1. 下载 root.crt。
  2. 双击证书，选择“安装证书”。
  3. 选择“本地计算机”，然后放入“受信任的根证书颁发机构”。
  4. 完成向导后，重新打开浏览器验证 HTTPS 访问。

Android

  1. 下载 root.crt。
  2. 在系统设置中搜索“安装证书”或“CA 证书”。
  3. 选择下载的证书文件，并按提示设置名称和用途。
  4. 注意：部分 App 不信任用户安装的 CA，但浏览器访问通常可用。

如果安装后仍然提示证书不可信，请确认访问地址是 https://， 并重启浏览器或相关 App。
