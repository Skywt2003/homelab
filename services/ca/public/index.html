设备设置

选择你的操作系统

下载证书后，按照对应平台的步骤完成安装。整个过程通常不到 2 分钟。

安装前请确认

只在你自己控制的设备上安装此根证书。这里提供的是公开证书，不是私钥。切勿分发 Caddy 数据目录中的 *.key 文件。

iOS / iPadOS

4 个步骤
  1. 01用 Safari 打开本页，下载 root.crt。
  2. 02打开“设置”，在顶部的“已下载描述文件”中完成安装。
  3. 03进入“设置 → 通用 → 关于本机 → 证书信任设置”。
  4. 04打开对 HomeLab Caddy 根证书的完全信任。

macOS

4 个步骤
  1. 01下载 root.crt，双击导入“钥匙串访问”。
  2. 02将证书放入“系统”钥匙串，或按使用范围放入“登录”钥匙串。
  3. 03打开证书详情，在“信任”中将 SSL 设置为“始终信任”。
  4. 04重新打开浏览器，访问 https://index.lab.skywt 验证。

Linux

4 个步骤
  1. 01下载 root.crt 到本机。
  2. 02Debian / Ubuntu：复制到 /usr/local/share/ca-certificates/lab-skywt.crt。
  3. 03运行 sudo update-ca-certificates。
  4. 04Fedora / RHEL：复制到 anchors 目录，然后运行 sudo update-ca-trust。

Windows

4 个步骤
  1. 01下载 root.crt。
  2. 02双击证书，选择“安装证书”。
  3. 03选择“本地计算机”，放入“受信任的根证书颁发机构”。
  4. 04完成向导后，重新打开浏览器验证 HTTPS 访问。

Android

4 个步骤
  1. 01下载 root.crt。
  2. 02在系统设置中搜索“安装证书”或“CA 证书”。
  3. 03选择下载的证书文件，并按提示设置名称和用途。
  4. 04部分 App 不信任用户安装的 CA，但浏览器访问通常可用。

仍然显示证书不可信？

确认访问地址以 https:// 开头，然后完全退出并重新打开浏览器。部分设备可能还需要重启。
